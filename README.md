# Simple Todo List

A simple todo list, now available for BTA!
![image](https://github.com/user-attachments/assets/be8c4f48-c001-4928-a56a-6e1cabf86eb8)

## Requirements
* The [BTA! Babric Instance](<https://github.com/Turnip-Labs/babric-instance-repo/releases/tag/v7.3_01>) for 7.3_01
* Nothing else!

## Notes/QnA
Q: Does this work on servers?

A: Yes! This is completely client-side and even saves your lists per server and world; saved in either a new directory or the SP world file. Do note that the server save is the server name; if you change it, your todo list will disappear unless moved!

Q: How many pages can you make?

A: Technically limitless! But each page, even empty, will save to the .dat file. Too many and your game may chug!
